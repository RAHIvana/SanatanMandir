# Shri Sanatan Mandir — website

Source for **shrisanatanmandir.org**, the website of Shri Sanatan Mandir (Sanatan Mandir of Austin), 281 Lemens Ave, Hutto TX.

It is a static website: plain HTML, CSS and a little JavaScript, generated by [Eleventy](https://www.11ty.dev/) from the files in `src/`. There is no database and no server to maintain. Events are small text files in `src/events/` (each becomes its own page); photos live in `photos/`.

## Pages

| Page | File | Notes |
| --- | --- | --- |
| Home | `src/index.njk` | Carousel, welcome, next 4 events, timings, gallery teaser |
| About | `src/about.njk` | Motto, mission, vision, deities, story, board & committee |
| Events | `src/events.njk` + `src/events/*.md` | Next event, upcoming tiles by month, past events; one page per event |
| Gallery | `src/gallery.njk` + `src/gallery-album.njk` | Albums generated from `photos/` |
| Priest Services | `src/priest-services.njk` | Profile, 26 services, request form |
| Weekend / Monthly / Kids Seva, Vidya Gurukulam | `src/seva-program.njk` (one template, four pages) | Content in `src/_data/programs.json` |
| Donate | `src/donate.njk` | Zelle + Venmo QR tiles, Square link, wishlist |
| Contact | `src/contact.njk` | Map, hours, social, newsletter form |

## Where to change things

Most day-to-day edits are in **`src/_data/`** — plain text files, no HTML needed:

| What | Where |
| --- | --- |
| Phone, email, address, hours, social links | `src/_data/site.json` |
| Google Form links (priest request, newsletter, each seva) | `src/_data/site.json` → `forms` |
| Zelle / Venmo IDs and QR images, Square link | `src/_data/site.json` → `payments` and `src/assets/img/*-qr*.png` |
| Events (add / edit / cancel) | `src/events/<date>-<name>.md` — see `docs/ADDING-EVENTS.md` |
| Committee names and roles | `src/_data/committee.json` |
| Services list and descriptions | `src/_data/services.json` |
| Seva / Gurukulam descriptions and schedules | `src/_data/programs.json` |
| Deity images and names (home page strip) | `src/_data/deities.json` + `src/assets/img/deity-*.png` |
| Professional albums hosted elsewhere | `src/_data/external_albums.json` |
| Menu items | `src/_data/nav.json` |
| Photo albums | `photos/<album-folder>/` — see `docs/ADDING-PHOTOS.md` |
| Static map on the Contact page | `src/assets/img/map-static.jpg` (+ `-600`) — a stitched OpenStreetMap image with the pin; replace with any screenshot of the same shape (5:3) if the location changes |
| Colors, fonts, layout | `src/assets/css/site.css` (palette tokens at the top: warm white, maroon, saffron, sand) |

Anything still waiting on content from the temple is shown on the live site inside a yellow dashed **PLACEHOLDER** box, so it is easy to spot. `docs/TEMPLE-CONTENT-CHECKLIST.md` lists all of them.

## Publishing

Pushing to the `main` branch publishes the site automatically (GitHub Actions → GitHub Pages) in one to two minutes. The site also rebuilds itself every morning so finished events move to the past list. Setup steps are in `docs/GITHUB-SETUP.md`; moving the real domain over is in `docs/DOMAIN-SWITCH.md`.

## Working locally (optional)

You do not need to run anything locally to publish, but if you want a live preview while editing:

```bash
npm install        # once
npm run dev        # opens http://localhost:8080 and reloads on save
npm run build      # writes the finished site to _site/
```

Requires Node.js 20 or newer.

## Folder map

```
src/            page templates, data files, CSS, JS, images, fonts
src/events/     one Markdown file per event (each gets its own page)
photos/         photo albums (one folder per event) — originals, never modified by the build
docs/           how-to guides for maintainers and volunteers
scripts/        one-off helper scripts (image optimisation of the old site's assets)
.github/        the GitHub Actions workflow that builds and publishes the site
_site/          the generated website (not committed; rebuilt on every push)
```
